# INNOVAPOLY UQ · Descargas

Juego de tablero sobre propiedad intelectual y transferencia de conocimiento.
Universidad del Quindío · Oficina de Innovación.

**Jugar en el navegador (sin instalar nada):** https://innovapoly-uq.onrender.com

## Descargar la app de escritorio

Ve a **[Releases → última versión](https://github.com/Pablit000x/innovapoly-uq-descargas/releases/latest)** y baja el archivo de tu sistema:

| Sistema | Archivo | Cómo abrirlo |
|---|---|---|
| Windows 10/11 | `INNOVAPOLY-UQ-…-win-x64.zip` | Descomprime el .zip y abre **INNOVAPOLY UQ.exe**. Si Windows muestra "Windows protegió su PC", pulsa *Más información → Ejecutar de todas formas*. |
| Linux | `INNOVAPOLY-UQ-…-linux-x86_64.AppImage` | Dale permiso de ejecución (`chmod +x`) y ábrelo. |

La app de escritorio sirve para los tres modos y es **la que se necesita para abrir una partida en red local (LAN)**:
el equipo que la abre muestra una dirección como `http://192.168.1.4:3900`, y los demás (computador o celular, en la
misma red WiFi) entran escribiéndola en su navegador. En Windows, la primera vez acepta el aviso del firewall para
**redes privadas**.

## Celular y tablet

Abre https://innovapoly-uq.onrender.com en Chrome (Android) o Safari (iPhone) y elige **Instalar app** /
**Agregar a la pantalla de inicio**. Queda con su ícono y el modo "En este equipo" funciona sin internet.
Se juega con el teléfono en horizontal.
